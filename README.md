# 🎬 SériesTip

SériesTip é uma página web desenvolvida por mim, com HTML e CSS que apresenta dicas e sugestões de séries organizadas por gêneros. 

## 🔗 Acesse o site:
➡️ [Clique aqui para ver o projeto publicado no GitHub Pages](https://luan-bernardo.github.io/projeto-seriestip/)

## 🧪 Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox
- Grid Layout
- Tipografia e cores modernas
